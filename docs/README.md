# Example docs

Everything in this folder belongs to **PetVida**, a fictional veterinary clinic app. It shows what each skill writes, so you can see the chain end to end. A real project builds its own `docs/` as it uses the skills.

| Path | Written by |
|---|---|
| `meetings/2026-10-01-online-booking/` (`transcript.md`, `minutes.md`), `meetings/glossary.md` | `/transcribe` (the routing section at the end of `minutes.md`: `/discovery`) |
| `features/appointment-booking/` (`README.md`, `understanding.md`, `research.md`, `product-analysis.md`, `rounds/1/`, `business-rules/`) | `/discovery` |
| `features/appointment-booking/screens.md` | `/design` |
| `features/appointment-booking/specs/` | `/architect` |
| `scope.md` | `/scope` |
| `design/` | `/penpot setup` |

Run `/start` here to see the board these files produce: `appointment-booking` is ready for `/develop`, `appointment-reminders` and `stack` are not started.
