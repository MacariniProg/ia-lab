# Components · PetVida DS

Generated by `/penpot setup` from the library. Reuse before creating a new component.

## Variant sets

| Component | Properties and values | When to use |
|---|---|---|
| Button | variant: primary, secondary, ghost · size: md, sm · state: default, disabled, loading | primary only for the screen's main action |
| Input | type: text, phone, email · state: default, focus, error, disabled | form fields |
| SlotChip | state: free, selected, unavailable | one slot in the list of free slots |
| AppointmentCard | status: confirmed, cancelled, attended, no show | one appointment in My appointments and in the day's schedule |
| Badge | tone: neutral, success, warning, danger | short status next to a title |
| Toast | tone: success, danger | the result of an action |
| EmptyState | kind: no-data, error | empty lists and loading failures |

## Simple components

- `icons/*`: 24 px icons (calendar, paw, phone, clock, close).
- `layout/*`: `layout/header-mobile`, `layout/header-desktop`, `layout/footer-phone`.
